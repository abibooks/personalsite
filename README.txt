# Ajithkumar Personal Website

A responsive single-page personal portfolio website built with:

- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
- Vanilla JavaScript

## Files

- `index.html` — main website
- `css/style.css` — theme and responsive styling
- `js/script.js` — navigation and small interactions

## Before publishing

1. Open `index.html`.
2. Replace the placeholder WhatsApp number `919999999999` in both WhatsApp links with the actual number, including country code and without `+` or spaces.
3. Replace the sample social media `#` links with real profile URLs.
4. Replace sample project/service content with your actual details.
5. Upload the folder to your hosting/server.

## Theme

Primary: Purple `#6c63ff`  
Secondary: Teal `#16c7b7`  
Accent: Warm Orange `#ffb86b`

The site uses a dark navy background and is mobile-first/responsive.
